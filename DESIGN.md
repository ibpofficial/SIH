# FreightIQ — Design System & Visual Identity

## Aesthetic Rationale: Maritime Industrial Dark Theme

FreightIQ is built specifically for maritime bulk commodity chartering desks and logistics decision-makers. Rather than using generic consumer SaaS light themes or violet gradients, FreightIQ employs a high-density dark aesthetic reminiscent of Bloomberg Terminals, Palantir Foundry, and real-time freight exchange platforms.

### Core Visual Principles
1. **Dark Slate Canvas (`#0B0F17` / `#111827`)**: Reduces eye fatigue during intensive monitoring sessions and highlights key metrics.
2. **Industrial Accent Color System**:
   - **Cyan / Baltic Teal (`#06B6D4` / `#0891B2`)**: Primary operational focus, navigation highlights, active selections.
   - **Amber / BDI Gold (`#F59E0B` / `#D97706`)**: Financial figures, procurement budgets, warning statuses.
   - **Emerald / Cargo Green (`#10B981`)**: Committed jobs, verified routes, high operational efficiency.
   - **Crimson / Risk Red (`#EF4444`)**: Rejections, draft capacity warnings, operational constraints.
3. **Typography**:
   - Monospace & Tabular Sans (`JetBrains Mono` / `Space Mono` / `Inter tabular-nums`): Prevents layout jitter in dynamic rate grids and numeric tables.
   - Grotesque Sans (`Inter` / `Outfit`): High-legibility headings and dense labels.
4. **Information Density**:
   - Hairline borders (`border-slate-800`).
   - Compact table cells with right-aligned numeric data.
   - Interactive command palette (`Cmd+K` / `Ctrl+K`) for rapid navigation.
5. **No AI Illusion**:
   - Future modules (Phase 2 forecasting & Phase 3 optimization) display honest "Under Construction / Phase 2" indicators rather than hardcoded mock figures.
